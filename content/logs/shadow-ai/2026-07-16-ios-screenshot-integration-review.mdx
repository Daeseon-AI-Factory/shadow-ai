## Pixel size was not the final gate

The four stored iPhone images each report 1320×2868, an accepted 6.9-inch portrait size. Visual inspection
still found two release-quality failures. The Practice capture enters a hidden route whose screenshot
shows only Home and a clipped raised-center bump instead of complete navigation. The Import capture has
a large empty blue/top region and does not make balanced use of the frame.

Home and Write retain the current five-tab navigation and remain source candidates. Practice and Import
stay in the repository as diagnostic captures, but the review packet now rejects them as submission
candidates rather than allowing pixel dimensions to imply visual approval.

iPad assets, optional Korean localization, and recapture from the exact archive selected for submission.
